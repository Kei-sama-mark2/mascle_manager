# mascle_manager

ジムでの筋トレ記録を管理する Web アプリ（Muscle Manager）です。
ビルド不要の HTML / CSS / JavaScript だけで動き、データはブラウザ（localStorage）に保存されます。

## 使い方

- `index.html` をブラウザで開くだけで使えます。
- スマホで使う場合は GitHub Pages などで公開し、「ホーム画面に追加」するとアプリのように使えます（オフライン対応）。
- ローカルで確認する場合: `python3 -m http.server 8000` を実行し http://localhost:8000 を開く。

## 主な機能

### 📝 記録
- 種目を選び、セットごとの **重量・回数** を入力（セット数は自動集計）
- **休憩時間**・RPE（きつさ）・メモ・その日の体重も記録
- 前回の記録・自己ベスト・目標までの残りを表示、「前回をコピー」で入力を省略
- 「📖 やり方」ボタンで、その種目の図解をすぐ確認
- 入力欄には前回の値がうっすら表示され、空欄のまま保存すると前回値で記録
- 自己ベストを更新すると 🎉 通知、記録には **PR** バッジ
- 入力途中の内容は自動保存（ブラウザを閉じても消えない）

### ⏱️ タイマー
- **休憩タイマー**: プリセット（30秒〜5分）、±15秒調整、終了時に音とバイブ
- 記録画面の「⏱ 休憩開始」から、その種目の休憩時間でタイマーを即スタート
- **ストップウォッチ**: スタート／ストップ／ラップ／リセット
- 動作中のタイマーはヘッダーに常時表示。時刻ベースで計測するので画面を閉じてもズレません

### 📅 履歴
- カレンダーでトレーニングした日をひと目で確認、タップでその日の記録へ
- 種目で絞り込める履歴一覧（編集・削除可能）

### 📈 統計
- 今週のトレーニング日数・総セット数・総ボリューム
- 今週鍛えた部位を筋肉マップで表示（まだ鍛えていない部位もお知らせ）
- 種目ごとの **最大重量（自己ベスト）** と推定1RM 一覧
- 最大重量 / 推定1RM / ボリューム / 体重の推移グラフ
- 1RM 計算機（Epley 式、回数ごとの目安重量）

### 🏋️ 種目（種目ガイド）
- 約60種目を収録（胸・背中・肩・腕・脚/お尻・腹）
- 部位を21の筋肉に細分化（例: 大胸筋上部/中部/下部、上腕二頭筋/上腕三頭筋/上腕筋/前腕）
- 各種目に **動く図解**（開始姿勢 ↔ 終了姿勢のアニメーション）、鍛えられる部位の **筋肉マップ**、やり方の手順、気をつけるポイント
- 名前・部位で検索（ひらがな入力OK）、部位・筋肉で絞り込み
- ☆で「マイメニュー」に追加すると記録画面で選べる。標準休憩・目標重量も種目ごとに設定
- オリジナル種目の追加
- JSON バックアップ／復元、CSV 出力（Excel で開けます）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | デザイン（ダークモード対応） |
| `app.js` | アプリ本体 |
| `exercises.js` | 種目ライブラリ（手順・ポイント・図のポーズ）と筋肉の定義 |
| `figure.js` | 種目の図（棒人間アニメーション）と筋肉マップの描画 |
| `sw.js` / `manifest.json` / `icon.svg` | PWA（オフライン・ホーム画面追加）用 |
